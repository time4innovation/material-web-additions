- **[2026-11-18] Bezug, Bau und Build-Freigabe: Ember-Parts holen den Fork von GitHub (`main`), pnpm baut ihn selbst und braucht dafür je Commit eine Freigabe in `allowBuilds` (`TKT-t4i-global-utilities-mui-components-002`, E2):**
  Betrifft: `material-web-additions` (externes Paket, Fork), `t4i-global-utilities-mui-components` (Ember-Origin-Addon) und `ecosoil-cms` (Ember-Projekt) als Bezieher (`package.json`: `github:time4innovation/material-web-additions`, `pnpm-workspace.yaml`: `allowBuilds`), pnpm 12.
  (1) Die gebauten Dateien (`*.js`, `*.css.ts`, `*.d.ts`) stehen in `.gitignore`; committet wird nur die Quelle (`.ts`, `.scss`). Beim Bezug lädt pnpm das Archiv des Commits und baut es per `prepare` → `pnpm run build` (wireit: sass → css → css.ts → tsc). (2) Die Bezieher nennen keinen Branch und keinen Commit: `pnpm update @maicol07/material-web-additions` nimmt den neuesten Commit auf `main` **auf GitHub**; der lokale Ordner zählt nicht. Ein Stand muss also gepusht **und** nach `main` gemergt sein, bevor ein Bezieher ihn bekommt. (3) pnpm 12 führt `prepare` eines Git-Pakets nur aus, wenn `allowBuilds` in der `pnpm-workspace.yaml` des Beziehers genau diesen Commit freigibt (`"@maicol07/material-web-additions@https://codeload.github.com/time4innovation/material-web-additions/tar.gz/<voller Hash>": true`); sonst bricht das Update mit `ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED` ab, ohne etwas zu schreiben. **Ablauf je neuem Stand:** im Fork `git fetch` (Hash von `origin/main` lesen), in jedem Bezieher den `allowBuilds`-Eintrag auf den neuen Hash setzen, `pnpm update @maicol07/material-web-additions`, dann prüfen: Lockdatei nennt nur den neuen Hash, `readlink -f node_modules/@maicol07/material-web-additions` zeigt auf die neue Version (ein alter Ordner unter `.pnpm` bleibt liegen, wird aber nicht genutzt), `grep` nach der Änderung in `data-table/internal/data-table.js`. Danach `ember serve` neu starten und Hard-Reload. (4) Lokaler Build im Fork zur Prüfung vor dem Push: `pnpm install` (läuft mit `prepare`, baut also schon) und `pnpm run build`; beides schreibt nur Gitignoriertes.
